PRIVACY POLICY

プライバシーポリシー

動画まるごと棋譜化（Android アプリ）

最終更新日: 2026年10月9日

本アプリは、撮影した動画を外部へ送信しません。解析はすべて端末の中で行います。アカウント登録も不要で、利用者を識別する情報を収集しません。

例外は1つだけです。利用者が「駒種のクラウド確認」を自分で有効にし、さらに画面上のボタンを押したときに限り、盤の1マスを切り出した小さな画像が外部のサーバへ送信されます。既定では無効です。

1. 収集しない情報

本アプリは次のいずれも収集しません。

  • 氏名・メールアドレス・電話番号などの個人を識別する情報
  • 端末の識別子（広告ID、端末ID など）
  • 位置情報
  • 連絡先、通話履歴、SMS
  • 利用状況の統計、クラッシュレポート、行動履歴

広告は表示しません。解析ツールも組み込んでいません。

2. 端末内で扱う情報

扱うもの目的保存先
利用者が選んだ動画盤面の解析端末内のみ。読み取るだけで複製も保存もしません
解析で得た棋譜（KIF 等）利用者が保存・共有するため利用者が指定した端末内の場所
診断ファイル認識がうまくいかないときの原因調査棋譜と同じ場所
画面の設定次回の利用時に引き継ぐ端末内（localStorage）
購入済みかどうか・無料で解析した局数3局までの無料の試用と、購入後の利用のため端末内（アプリの設定領域）

これらが端末の外へ出ることはありません。棋譜や診断ファイルを他者へ渡すかどうかは、利用者が共有操作を行ったときにのみ決まります。

購入について。購入の手続きと支払いは Google Play が行います。本アプリと開発者は、カード番号などの支払い情報を受け取りません。購入済みかどうかは、アプリが Google Play に問い合わせて確かめ、その結果を端末内に記録します。

3. 「駒種のクラウド確認」について

将棋の盤面は、駒がどこにあるかだけでは駒を打った手と成った手を区別できません。この2つに限り、駒の見た目を読む必要があります。本アプリは端末内の判定で処理しますが、判断が難しい手について、利用者の希望により外部の AI に問い合わせる機能を備えています。

送信されるもの

  • 盤の1マスを切り出した画像（およそ 150 × 150 画素、数KB）
  • その画像だけです。動画そのもの、棋譜、対局者名、端末の情報は送信しません。

送信される条件（すべて満たしたときだけ）

  • 利用者が設定画面で「駒種のクラウド確認」を有効にしている（既定は無効）
  • 利用者が API キーを自分で入力している、または中継サーバを設定している
  • 利用者が画面上の確認ボタンを押した

自動では送信されません。バックグラウンドで送ることもありません。

送信先

  • 利用者が自分の API キーを使う場合: Anthropic 社の API（api.anthropic.com）
  • 中継サーバを使う場合: 利用者が設定したサーバ

送信先での取り扱いは、それぞれの事業者のプライバシーポリシーに従います。本アプリの開発者は、送信された画像を受け取りません。

API キーの保管

利用者が入力した API キーは、端末内にのみ保存されます（localStorage）。開発者を含む第三者へ送信されることはありません。アプリを削除すると消えます。

4. 権限

権限用途
インターネット（INTERNET）アプリ内部の通信、および上記のクラウド確認を有効にした場合のみ
通知・実行中の処理（POST_NOTIFICATIONS・FOREGROUND_SERVICE・WAKE_LOCK）解析中であることを通知で示し、通知から中止できるようにするため
アプリ内購入（BILLING）Google Play での購入と、購入済みかどうかの確認のため

カメラ権限は要求しません。「その場で撮る」は端末のカメラアプリに処理を任せます。

5. 子どもの利用について

本アプリは特定の年齢層を対象としていません。個人情報を収集しないため、子どもから情報を集めることもありません。

6. 第三者提供

本アプリは、利用者の情報を第三者へ提供・販売しません。第3項のクラウド確認は、利用者自身の操作による送信であり、開発者による提供ではありません。

7. 変更

本ポリシーを変更する場合は、本ページを更新し、最終更新日を改めます。送信するデータの種類や条件を変える変更は、アプリの更新時に画面でお知らせします。
